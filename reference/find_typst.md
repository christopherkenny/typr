# Find if Typst is available

Find if Typst is available

## Usage

``` r
has_any_typst()

has_typst_cli()

has_quarto_typst()

has_quarto_cli()

typr_has_typst()

typr_has_quarto()

typr_has_quarto_typst()
```

## Value

a logical if Typst or Quarto are found

## Examples

``` r
has_any_typst()
#> [1] FALSE
has_typst_cli()
#> [1] FALSE
has_quarto_cli()
#> [1] FALSE
has_quarto_typst()
#> [1] FALSE
```
